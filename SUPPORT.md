# Support

For bug reports, formatting edge cases and feature requests, please open an issue in the project's public repository.

When reporting a formatting issue, include:

1. the selected input code;
2. the expected formatted result;
3. the actual result;
4. your VS Code version;
5. whether the code is in `.py` or `.ipynb`.

Do not include secrets, credentials, customer data or other confidential information in issue reports.
